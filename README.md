# 📝 Notes App - Full Stack Pre-Task

A beautifully designed, full-stack note-taking application built for the Sudu.ai internship pre-task. It allows users to Create, Read, Update, and Delete text-based notes with a modern, animated UI.

## ✨ Features
- ✍️ **Create** notes with a title and content.
- 📋 **Read** / View all notes in a responsive card layout.
- 🔄 **Update** existing notes seamlessly.
- 🗑️ **Delete** notes with a confirmation prompt.
- 🎨 **Glassmorphism UI** with animated gradient backgrounds and smooth micro-interactions.

## 🛠️ Tech Stack
- **Frontend:** Vue 3 (Composition API), Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** SQLite3 (with `sqlite` wrapper for async/await)
